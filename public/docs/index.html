Introduction

API تطبيق وين (Wain): الأماكن والتصنيفات والحساب. العقد بين الـ backend والموبايل.

Base URL: http://localhost 
الـ API ده هو العقد بين الـ backend والموبايل. أي تغيير في شكل الـ response أو البارامترات بيتكتب هنا
الأول (في الـ PR نفسه) وبيتقال لمعلوم، والملفات دي بتتولّد بـ `php artisan scribe:generate`.

- **المسار الأساسي:** `/api/v1`، JSON فقط.
- **الدخول:** `Authorization: Bearer <token>` (Sanctum، صلاحية 30 يوم). الـ endpoints العامة بتقبل token اختياري.
- **اللغة:** هيدر `Accept-Language: ar` (الافتراضي) أو `en`. الحقل الإنجليزي الفاضي بيرجع العربي.
- **الأخطاء:** `{ "message": "...", "code": "PLACE_NOT_AVAILABLE", "errors": { } }`. `errors` في 422 بس. الأكواد في `06-Data-Model-and-API.md`.
- **الأرقام:** اللاتينية (4.3، 150). الوقت بتوقيت القاهرة، والتخزين UTC.
- **حد الطلبات:** 60 طلب في الدقيقة للزائر و120 للمستخدم المسجّل. الزيادة `429 TOO_MANY_REQUESTS` ومعاها هيدر `Retry-After` بالثواني (وهيدرز `X-RateLimit-Limit` و`X-RateLimit-Remaining`). الزائر بيتحسب بالجهاز (هيدر `X-Device-Id`) ومن غيره بالـ IP. الدخول والتسجيل ونسيت الباسورد وأكواد الإيميل ليها حد أضيق (5 في الدقيقة) مكتوب عند كل endpoint.

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

الـ token بيرجع من POST /auth/register أو POST /auth/login. الـ endpoints العامة بتشتغل من غيره، ولو بعتّه بيتفعّل is_saved.

Auth

POST /auth/register — بيعمل الحساب ويرجّع token، فالمستخدم يدخل على طول.

    "http://localhost/api/v1/auth/register" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \

    --data "{
    \"name\": \"b\",
    \"email\": \"zbailey@example.net\",
    \"password\": \"|]|{+-\",

Forgot password: send a code

بيبعت كود 6 أرقام للإيميل (صالح 15 دقيقة، و5 محاولات). الرد واحد دايماً سواء الإيميل مسجّل أو لأ، عشان ما نكشفش مين عنده حساب. وهو نفسه «ابعت تاني»: لو لسه ما عدّتش 60 ثانية من آخر إرسال بيرجّع نفس الرد من غير ما يبعت كود جديد، وresend_in هو الباقي بالثواني. الكود الجديد بيلغي القديم.

5 محاولات في الدقيقة لكل IP + إيميل، ولكل خطوة من الـ 3 (forgot وverify وreset) ميزانيتها لوحدها (429 TOO_MANY_REQUESTS ومعاه هيدر Retry-After).

Check the code

بيتحقق من الكود. لو صح بيرجّع reset_token (لمرة واحدة، صالح 10 دقايق) يتبعت مع الباسورد الجديد، عشان شاشة الكود تتحقق قبل ما تفتح شاشة الباسورد.

  • INVALID_CODE: الكود غلط (أو مفيش كود مطلوب).

  • CODE_ATTEMPTS_EXCEEDED: خلّص الـ 5 محاولات، اطلب كود جديد.

Set the new password

بيغيّر الباسورد بالـ reset_token (مرة واحدة). كل الـ tokens القديمة بتتمسح، فالمستخدم يدخل من جديد بالباسورد الجديد (204). الكود اللي وصل للإيميل بيثبّت إن الإيميل بتاعه، فالحساب بيتأكّد.

  • RESET_TOKEN_INVALID (422): الـ token غلط أو منتهي أو اتستخدم، ابدأ من أول.
  • أخطاء الباسورد (422 VALIDATION_ERROR) تحت حقل password.
Example request:
curl --request POST \
    "http://localhost/api/v1/auth/password/reset" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --header "Accept-Language: ar" \
    --data "{
    \"email\": \"user@example.com\",
    \"reset_token\": \"k3Jx...\",
    \"password\": \"newpass123\"
}"

const url = new URL(
    "http://localhost/api/v1/auth/password/reset"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
    "Accept-Language": "ar",
};

let body = {
    "email": "user@example.com",

Get place details

تفاصيل المكان. صفحة المكان (F7): كل حقول الكارت + الوصف والعنوان والتصنيفات والخصائص (متجمّعة) والتواصل والمواعيد والصور والمنيو.

  • بيرجّع المنشور (status = active) والمغلق نهائياً (status = closed) بس. غير كده (مخفي أو مسودة أو قيد المراجعة أو مرفوض أو محذوف أو مش موجود) 404 PLACE_NOT_AVAILABLE واحدة من غير ما تكشف السبب.
  • المغلق نهائياً: is_open_now وhours.status_text بـ null وhours.week فاضية، والموبايل بيعرض بانر «المكان ده قفل نهائياً» وبيخفي أزرار التواصل.
  • الـ slug القديم بعد ما يتغيّر بيرجّع المكان بالـ slug الجديد (الروابط المتشاركة تفضل شغالة).
  • الأجزاء الفاضية: description بـ null، وattributes وphotos وmenu_photos قايمة فاضية، وحقول contact بـ null.
  • distance_km بـ null من غير lat وlng. is_saved دايماً false لحد F9.
  • بيانات المكان في cache لمدة 5 دقايق وبتتمسح فوراً مع أي تعديل أو إخفاء. is_open_now والمواعيد واللغة وdistance_km بتتحسب مع كل طلب.

  • المرادفات: كوفي = كافيه = cafe = coffee، وروف = roof = rooftop، وشيشة = shisha (قاموس في الـ repo).
  • الفرانكو: بيتطابق بالـ search_aliases اللي الأدمن بيضيفها للمكان وبقاموس المرادفات.
  • الكلمات: كل كلمة لازم تكون موجودة (AND). الاسم أول، بعده الـ alias، بعده الباقي.
  • التصحيح الإملائي: لو النتايج أقل من 3 بتتصحّح الكلمات الغلط، وmeta.corrected_query بيرجع بالكلمة اللي اتبحث بيها فعلاً (null لو ما اتصحّحش حاجة). الموبايل بيعرض «نتايج لـ …».
  • الترتيب: sort=recommended (الافتراضي) بيرتّب بالتطابق الأول ثم بالترتيب المقترح، والباقي (nearest وrating وnewest) بترتيبها زي القائمة.
  • علامات الترقيم بس (أو كلمة من غير حروف) بترجّع قايمة فاضية مش خطأ.
  • log=1: بيسجّل العملية في سجل البحث (الكلمة مطبَّعة والمنطقة وعدد النتايج والمستخدم والجهاز) لتقارير «أكتر بحث» و«بحث من غير نتائج». الموبايل بيبعتها لما المستخدم يدوس Enter أو يفتح نتيجة أو تثبت شاشة «مفيش نتائج» لثانية بس. السجل بيتمسح بعد 90 يوم.

Search suggestions

اقتراحات سريعة وهو بيكتب (typeahead): أحسن 6 أماكن منشورة لللي اتكتب لحد دلوقتي، بصف صغير لكل مكان (الاسم والتصنيف والمنطقة وصورة مصغّرة). الموبايل بيعرضها تحت حقل البحث، والضغط على اقتراح بيفتح المكان مباشرة، والنتايج الكاملة (كروت وفلاتر وترتيب) من GET /search لما المستخدم يدوس بحث.

  • نفس البحث: نفس التطبيع والمرادفات والتصحيح الإملائي والترتيب بتاع GET /search (بداية كلمة في الاسم قبل جوه الاسم قبل الباقي)، فالاقتراحات متتناقضش مع النتايج. meta.corrected_query بيرجع بالكلمة المصحّحة لو اتصحّحت.
  • من غير فلاتر ولا pagination ولا عدّاد: استعلام واحد صغير بدل استعلام النتايج كله، عشان يتبعت مع كل وقفة في الكتابة.
  • حد خاص بيه: مش بيتحسب على الحد العام للتطبيق (60 زائر / 120 مستخدم في الدقيقة)، وله حده الواسع (WAIN_RATE_LIMIT_SUGGEST_GUEST/_USER، 120 و240)، فكتابة كتير ما تحجبش الرئيسية ولا صفحة المكان.
  • علامات الترقيم بس (أو كلمة من غير حروف) بترجّع قايمة فاضية مش خطأ.
